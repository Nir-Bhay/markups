Policy / Accessibility

Accessibility Statement

Markups is built for keyboard-first editing and responsive use across desktop and mobile devices, with shortcuts and layout controls that reduce friction for many writing workflows.

Direct answer

The core experience is designed to work with keyboard shortcuts, split-pane layouts, and standard browser controls. If an interaction is hard to use with your assistive technology, we want that feedback so it can be improved.

Current strengths

  • Keyboard shortcuts for save, export, import, formatting, focus mode, and fullscreen.
  • Responsive layouts that adapt to mobile and desktop screens.
  • Clear text-based markdown workflows that work without a sign-in step.

Practical notes

  • Browser zoom and system font scaling should remain usable.
  • Use your browser's built-in accessibility tools with the editor.
  • High-contrast support depends on your browser and system theme choices.

Keyboard shortcuts

Common shortcuts include save, export, import, formatting, focus mode, fullscreen, and help. The exact key map is documented in the main product README and inside the app.

Feedback

If you hit an accessibility barrier, please file an issue at github.com/Nir-Bhay/markups/issues. Please include your browser, device, and a short description of the problem.
