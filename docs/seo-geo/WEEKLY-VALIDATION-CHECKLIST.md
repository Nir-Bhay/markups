# Weekly Validation Checklist

## Technical SEO

- [ ] Sitemap URLs are live and return expected status codes
- [ ] Canonical tags match `markups.dev` policy
- [ ] Robots and llms files are accessible and unchanged unexpectedly
- [ ] No newly introduced broken internal links in SEO pages

## GEO/AEO

- [ ] Structured data remains truthful and visible on page
- [ ] No unverifiable review/rating claims introduced
- [ ] Answer blocks remain intact on ranking pages

## Content & Linking

- [ ] Newly published pages are linked from relevant hubs
- [ ] No orphan SEO pages
- [ ] Anchors are descriptive and intent-matched

## Measurement

- [ ] Log weekly trend notes in current run log
- [ ] Flag any ranking/crawl anomalies for next sprint
