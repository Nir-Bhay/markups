# Wave 1 Page Map (High Intent, Low Risk)

## Wave Goal

Capture the strongest BOFU + comparison demand first with minimal product risk.

## Publishing Scope

- New SEO pages in a marketing/docs surface (recommended path family: `/seo/`).
- Keep app runtime untouched.
- All pages link to `https://markups.dev` as primary CTA destination.

## Required Elements Per Page

- Direct answer introduction (40-60 words)
- Feature proof section tied to actual product behavior
- FAQ section with high-likelihood user questions
- One comparison table (for comparison pages)
- Clear CTA to app (`/`) and landing (`/landing`)

## Exclusions (Wave 1)

- No broad tutorial hub yet
- No major design rewrites
- No unverified benchmark claims
