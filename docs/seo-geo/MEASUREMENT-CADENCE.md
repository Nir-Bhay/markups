# Measurement and Optimization Cadence

## Weekly Routine

Owner: QA/Evidence + Technical SEO

1. Check crawl/index issues.
2. Check top query movements by cluster.
3. Validate recent changes did not create metadata/schema regressions.
4. Update run logs and backlog statuses.

## Monthly Routine

Owner: Orchestrator + GEO/AEO + Content Strategy

1. Compare month-over-month visibility by cluster.
2. Review AI citation presence for tracked query set.
3. Promote/deprioritize backlog items by impact.
4. Approve next content wave.

## KPI Set

- Organic impressions
- Organic clicks
- CTR
- Avg position for tracked terms
- Indexed pages
- Crawl/index errors
- AI citation share (manual/tool-assisted tracking)
- Engagement quality on SEO landing pages

## Change-to-Impact Log Rule

Every execution run must include:

- What changed
- Why it changed
- Expected KPI impact
- Observation window
- Actual result after review
