## How to choose the next keyword from actual evidence

After deployment/indexing, inspect GSC Pages → chosen URL → Queries over complete 28/90-day windows. Group genuine problem wording by intent, not exact text variants. A recurring query matching the current answer is a reason to improve the page. A materially different problem may justify a new page. With tiny/anonymized samples, label the decision exploratory. Recheck relevant SERPs and primary specifications; use a permitted keyword database for country-specific estimates if available. Do not label qualitative current search results “top trending.”

## Publishing standard

One clear problem, direct answer, reproducible example, actual output, compatibility boundary, primary sources, honest date, related reference, and optional tool mention. No keyword-stuffed paragraph, fake benchmark or chart with invented data. Use graphs only when they explain a concrete path or comparison; generic diagrams should be replaced with topic-specific figures. Human review should assess whether the article helps without requiring a product click.
