# SEO Content Wave Release Cadence

## Ownership

- Orchestrator: scope lock, scheduling, go/no-go
- Content Strategy: briefs and content QA
- GEO/AEO: extractability and citation-readiness pass
- Technical SEO: metadata/schema/indexability checks
- QA/Evidence: final acceptance and run logging

## Cadence

### Weekly
- Monday: finalize page briefs for next batch
- Wednesday: draft + internal linking pass
- Friday: QA + release batch

### Monthly
- Week 1: Wave planning and reprioritization
- Week 2-3: Execution batches
- Week 4: KPI review and backlog adjustments

## Batch Size Rules

- Max 3-5 pages per release batch.
- Do not mix unrelated cluster pages in one batch unless linked deliberately.
- Hold publication if schema/metadata QA fails.

## Release Checklist

- [ ] Brief completed from `PAGE-BRIEF-TEMPLATE.md`
- [ ] GEO/AEO structure pass completed
- [ ] Internal links applied per blueprint
- [ ] Metadata + canonical validated
- [ ] Run log created in `docs/seo-geo/runs/`
