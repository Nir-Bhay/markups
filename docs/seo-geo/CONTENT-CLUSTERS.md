# SEO Content Clusters (Full-Site Plan)

## Cluster 1 - BOFU Tool Intent (Priority 1)

Target intent: users ready to use a markdown tool now.

- online markdown editor
- markdown to pdf
- markdown to html
- markdown to docx
- markdown live preview editor

## Cluster 2 - Comparison Intent (Priority 1)

Target intent: users choosing between products.

- markups vs typora
- typora alternative
- stackedit alternative
- best markdown editor for developers

## Cluster 3 - Developer Workflow Intent (Priority 1)

Target intent: practical documentation and coding workflows.

- README markdown editor
- markdown editor for GitHub docs
- API docs markdown workflow
- changelog markdown template

## Cluster 4 - Advanced Markdown Intent (Priority 2)

Target intent: users who need advanced syntax features.

- mermaid markdown editor
- latex markdown editor
- gfm editor online
- markdown table/task-list tooling

## Cluster 5 - Productivity Intent (Priority 2)

Target intent: focused writing users.

- distraction-free markdown editor
- typewriter mode editor
- offline markdown editor PWA
- writing goals markdown editor

## Cluster 6 - Educational Intent (Priority 3)

Target intent: tutorial and discoverability funnel.

- how to write a README in markdown
- markdown for documentation teams
- mermaid in markdown tutorial
- markdown export best practices

## Wave Plan

- **Wave 1**: Cluster 1 + 2 (highest revenue/activation potential)
- **Wave 2**: Cluster 3 + 4
- **Wave 3**: Cluster 5 + 6

## Internal Linking Rules

- Every cluster has one pillar page and multiple support pages.
- Support pages link up to pillar using descriptive anchors.
- Pillar pages cross-link to neighboring cluster pillars.
