# 🚀 Markups Future Scope

> This document describes the long-term vision, roadmap, and future features planned for Markups.

## Vision
Markups aims to become a modern offline-first markdown workspace combining the best ideas from editors like Notion, Obsidian, HackMD, GitBook and VS Code.

## Planned Roadmap

### Phase 1
- Shareable URLs
- Cloud Sync
- Authentication
- Version History

### Phase 2
- Real-time Collaboration
- Comments
- Permissions
- Workspace Sync

### Phase 3
- AI Assistant
- GitHub Sync
- Plugin System
- Publishing

### Phase 4
- Knowledge Graph
- Enterprise Features
- Analytics
- Public API

> A much more detailed technical specification, architecture, proof-of-concepts, database schemas, API contracts, and implementation guides will be expanded in future revisions of this document.
