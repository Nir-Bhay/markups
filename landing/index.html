How Markups works

One editor, one preview, no account. This page shows each state. The button opens the real editor.

Notes

Write on the left. The preview is the same text.

The right pane is a view of the Markdown, not a second file. Headings, lists, links, tables, and fenced code update there as you type.

If the preview looks wrong, the fix is in the source. The preview does not invent a sentence that is not in the Markdown.

What the PDF and Word buttons save

.pdf

A picture of the preview. Letter, portrait, three-quarter inch margin.

.doc

Word-compatible HTML, saved under a .doc name.

PDF export is a picture of the preview. It is not a text PDF you can select and search.

The Word button saves Word-compatible HTML as a .doc file. It is not an OOXML package, and it does not include Track Changes.

Limits

Not a text PDF

The PDF is a picture of the preview.

Not a native Word file

The Word button writes HTML under a .doc name.

HTML and Markdown

HTML export is a separate save. Raw Markdown is the source to keep if you want to edit again.

Not full offline use

A page that already loaded can appear again if the network drops. That is not the same as opening the editor with no network from the start.

Questions

Does Markups require an account?

No. There is no account.

What do the PDF and Word buttons save?

PDF export is a picture of the preview. The Word button saves Word-compatible HTML as a .doc file.

When does a mermaid block become an SVG?

A mermaid block becomes an SVG after the first paint, not on the first paint.

What happens if math is turned off?

Turning math off removes the formula and does not restore the TeX source. YouTube insert is included.
