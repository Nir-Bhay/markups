07 / FAQ

Questions worth asking.

Clear answers before you rely on a tool for your writing.

Read our data-handling policy ↗
Is Markups really free?

Yes. You can use the core editor and preview without a paid plan or account. The source code is MIT licensed.

Do I need to create an account?

No. Open the Markdown editor and start writing. Drafts normally live in your browser; exporting a Markdown copy helps protect your work if browser storage is cleared.

Can I render Mermaid and LaTeX math?

Yes. Mermaid code fences and KaTeX math are supported in the preview. For examples, see diagrams and math.

Does the exported PDF contain selectable text?

No. It is an image-based PDF, not a searchable or accessibility-tagged PDF. If selectable text matters, keep the Markdown or HTML document.

Can I export a native .docx file?

Not currently. The Word-compatible output uses HTML with a .doc filename. Always inspect diagrams and equations in the application you use to open it.

Does my Markdown stay private?

Normal editing saves drafts in browser storage. Optional AI and sharing features may process selected data differently; see the privacy policy for specifics.
