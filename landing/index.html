07 / GOOD QUESTIONS

A little more
clarity.

Here is what you should know before you start writing.

Is Markups free, and do I have to create an account?+

Markups is free to use and open source. You can open the browser editor without signing up.

Will my Markdown be uploaded to a server?+

Normal editing stores drafts in your browser. Optional AI features can send content you choose to a configured model provider, and sharing/exporting can move content out of the browser. Review the privacy policy for the details.

Does Markups support Mermaid and KaTeX?+

Yes. Mermaid diagrams and KaTeX equations can be rendered in the preview while their source stays in your Markdown document.

Is the PDF selectable and is Word export a true DOCX?+

Not currently. PDF export is based on a picture of the preview. Word-compatible export saves HTML using a .doc extension rather than native DOCX.

Can I use the editor with no internet connection?+

A previously loaded page may be available from browser cache, but a reliable cold-start offline experience is not guaranteed. Export Markdown to keep a backup.

Where can I inspect the source code?+

The project is MIT licensed. See the public GitHub repository for code, issues and development instructions.
