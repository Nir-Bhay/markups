How Markups works

One tab. You write Markdown on the left and read the preview on the right. There is no signup. This page only explains that editor. The button opens it.

Open the editor

1. Open it and write

The session starts on the editor. This walkthrough is not a second product, and it does not ask for an account.

No account

There is no signup form in front of the document. You open the editor in the browser tab you already have. The writing pane is the Monaco editor. What you type stays Markdown. The preview is a view of that same text, not a different file.

What you can type

Headings, emphasis, lists, links, tables, and fenced code. The left pane is the source you edit. If the preview looks wrong, the fix is in that source. The preview does not invent a sentence that is not in the Markdown.

If the network drops

A page that already loaded can appear again if the connection drops. That is not the same as opening the editor with no network from the start. This is not full offline use.

Where the writing happens

The frame above is the real editor. The sections below are the objections that a button label does not answer: when a diagram appears, what math-off does, and what each export file actually is.

2. Read the other pane

The right pane is the live split preview. Most of the document updates as you type. Two things do not behave like the rest.

What updates as you type

Headings, paragraphs, lists, links, tables, and fenced code show up from the Markdown on the left. On a wide screen the panes sit side by side. Use the preview to check structure before you export.

Mermaid waits

A mermaid block becomes an SVG after the first paint, not on the first paint. The first look at the page is still the fence. If you turn the preview off, the fence stays a code block. It is not a separate drawing tool. You edit the source inside the fence.

Math on

KaTeX renders inline and display math in the preview. A centered equation is still a line of TeX in the editor. The preview is where it becomes a typeset formula. The source stays in the editor while math is on.

Math off

Turning math off removes the formula and does not restore the TeX source in the preview. The dollar-sign line does not come back in that pane. If you need the source, it is still in the editor.

3. Put a video in the document

YouTube insert is included. The preview shows the embed. The Markdown still holds the reference you typed.

What this is, and what it is not

Use the insert control and paste a YouTube URL. The preview embeds that video in the document. This is not a video editor. It does not trim, caption, or re-encode the clip. It places the video in the page you are writing, next to the headings and lists already in the source.

4. Save a copy out

The button name is shorter than the file it writes. Read this before you send a file to someone else.

PDF

PDF export is a picture of the preview. The page is letter size, portrait, with a three-quarter inch margin. It is a picture of the preview pane, not a text PDF you can select and search. A diagram or a formula appears only as it looks in that picture.

Word

The Word button saves Word-compatible HTML as a .doc file. It is not an OOXML .docx package, and it does not include Track Changes or other Word review markup. Opening it in Word is not the same as receiving a native Word document.

HTML

HTML export is a separate save of the rendered document as a web file. Use it when the next step is a browser, not a word processor. It is not the same button as the Word save.

Markdown

You can also save the raw Markdown. That file is the source. It is the copy to keep if you want to edit the document again later. Export does not replace that source with the preview.
