How it works

Open the editor, write on the left, and read the preview on the right.

1

No signup

Open the editor in the browser. An account is not required.

2

Split preview

The editor is on the left. The live preview is on the right.

3

Math, video, diagrams

KaTeX renders math. YouTube insert is included. A mermaid block becomes an SVG after the first paint, not on the first paint. Turning math off removes the formula and does not put the TeX source back.

What export saves

PDF

The PDF button saves a picture of the preview. It is not a text PDF.

Word

The Word button saves Word-compatible HTML as a .doc file. It is not an OOXML DOCX.

HTML and Markdown

HTML is a separate save. You can also save the raw Markdown file.
