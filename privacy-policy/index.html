Privacy Policy

Markups is designed so your editor content stays in your browser, while public pages may use limited analytics and diagnostics to understand traffic and keep the site stable.

Direct answer

Normal editing and autosave store drafts in your browser, without an account. If optional cloud backup or connected-account features are configured for a build, they require sign-in or provider authorization and a separate user action before selected document content is sent. The hosted editor may load limited analytics on clean URLs at markups.dev; it skips tracker requests on preview builds, local builds, URLs with document fragments, and URLs with unapproved query parameters. The current development build has no Appwrite project configured.

What we collect

  • On the hosted editor, Google Analytics receives the clean page path, a generic page title, the referring site origin, and allowlisted campaign source/medium/name values. It may also receive an editor_start event and an export_completed event with the format only (for example PDF or HTML). These events do not contain draft text, document titles, filenames, API keys, or share links.
  • Microsoft Clarity session replay is not loaded on the editor. The full editor body also carries an explicit Clarity mask as defense in depth if replay is re-enabled later.
  • Vercel Web Analytics may collect page and performance signals on clean hosted editor URLs.
  • Approximate location derived from IP address through analytics providers.
  • Any message you send through GitHub issues or the repository.

What we do not collect

  • Your draft Markdown content as part of normal editing or in the configured Google Analytics/Vercel event payloads. Clarity session replay is not loaded on the editor.
  • Account credentials during normal local editing. Optional account features, when configured and used, necessarily process sign-in and session data.
  • Draft uploads during normal editing. Optional cloud backup sends only a document you explicitly select and consent to save; local image attachments are not included in cloud backup.

Why we process data

Service operation

To deliver pages, protect the site from abuse, and keep the public experience working as expected.

Measurement and improvement

To understand which pages are useful, identify broken experiences, and improve the public site.

Third-party services

The hosted editor, product landing page, Markdown guides, and blog may load Google Analytics and Vercel Web Analytics on clean URLs at markups.dev. Analytics scripts are not loaded on local or preview builds, any URL containing a fragment, or URLs with query parameters outside the allowlisted campaign source/medium/name set. The current telemetry bootstrap does not load Clarity session replay. Google Analytics gets a sanitized path and origin-only referrer rather than the full page URL. Public content pages use their published page title; the editor uses a fixed title so draft titles are not sent. These providers may process other technical data, such as device information and approximate location, under their own policies. Markups also loads fonts and links to GitHub.

Optional AI Writer and document sharing

Ordinary Markdown editing does not require an AI provider or an account. If you choose to use AI Writer, Markups sends the prompt and any selected document text or surrounding context included in that request to the AI endpoint you configure. The selected provider, and any enabled routing service, may process that request under their own terms and privacy policy. Do not submit sensitive content unless you understand the recipient.

AI Writer accepts your own API key. You can choose a session-only key held in browser memory, or opt to remember the key in local browser storage. A remembered key can remain available to scripts running on this origin until you clear it; do not use it on an untrusted device. The app does not require an AI key for normal editing.

The optional share link feature encodes a document title and Markdown content into the URL fragment. Anyone with the full link can decode and read the shared content. Treat that URL as containing the document itself; do not share private documents or secrets this way. The browser and installed extensions may also retain link history.

Your rights

  • Access the data we hold about you, if any.
  • Ask us to delete personal data that we control.
  • Object to or limit processing where the law allows it.
  • Withdraw consent where consent is the legal basis.
  • Use browser settings to clear local storage, cookies, and site data.
