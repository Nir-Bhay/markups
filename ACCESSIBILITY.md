# Accessibility

Markups aims to support keyboard navigation, readable contrast and responsive writing workflows. This is a commitment to improvement, not a claim of full WCAG conformance.

The editor uses Monaco, which provides screen-reader and keyboard features. Real assistive-technology acceptance across the whole application remains incomplete. PDF exports are image-based and do not provide a fully tagged/selectable-text document. Word-compatible export is HTML `.doc`, not native DOCX.

Report barriers with the bug-report form: describe the task, browser/OS, assistive technology and version, steps, and expected versus actual behavior. Use disposable examples and omit private documents. We cannot promise a resolution date; maintainers will assess the impact and practical fix.

See the public [accessibility statement](https://markups.dev/accessibility) and [contribution guide](CONTRIBUTING.md).
