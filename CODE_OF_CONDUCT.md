# Community Code of Conduct

Markups welcomes people of every experience level and background. Treat contributors and users with respect in issues, pull requests and other project spaces.

## Expected behavior

- Be considerate and constructive; discuss ideas and code without personal attacks.
- Respect different experiences and viewpoints, and accept corrections in good faith.
- Protect privacy. Do not publish someone's personal information, credentials or private documents.

Harassment, discriminatory language, sexualized attention, threats, trolling and sustained disruption are unacceptable.

## Reporting and enforcement

Report concerns privately to [Nir-Bhay through the contact options on the maintainer's GitHub profile](https://github.com/Nir-Bhay). Do not post private incident details in public issues. Security vulnerabilities use the separate route in [SECURITY.md](SECURITY.md).

Maintainers will assess reports and may edit or remove content, request a change in behavior, restrict participation temporarily, or ban repeat or serious offenders. Responses should reflect severity and context. Reports should be handled discreetly; confidentiality cannot be promised where platform intervention or protection of others requires disclosure. No fixed response time is promised.

This policy covers project spaces and conduct while representing the project. It does not appoint community members as official project representatives.
